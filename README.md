# Heaps Good Studio Homebrew tap

Homebrew formulae for Heaps Good Studio tools.

## agent-observability

A local dashboard for Claude Code and Codex usage, allowances and sessions. macOS only.

```bash
brew install heapsgoodstudio/tap/agent-observability
claude-obs install
```

After each `brew upgrade agent-observability`, run `claude-obs install --upgrade`. Before `brew uninstall agent-observability`, run `claude-obs uninstall`. See [heapsgoodstudio/agent-observability](https://github.com/heapsgoodstudio/agent-observability).

Each formula here is written by its project's release workflow, so change it in that project rather than in this repository.
